  - 부문별 매출(비중)은 공시·금융포털에서 확인 가능(위 수치들). 다만 부문별 영업이익·영업이익률은 회사 공시상 표준적으로 분리 제공되지 않아 “정확한 공시값”을 제시할 수 없음(따라서 부문별 이익은 추정만 가능). ([financialfilings.com](https://financialfilings.com/filings/hannong-chemicals-inc/audit-report-information/2026/32982573/))  
  - 2026년 상반기(특히 Q2)로 실적이 개선(매출·영업이익 모두 증가) — Q1→Q2에서 GE 중심으로 매출·수익성 개선 신호가 리포트에서 반복 보고됨. ([kosai.kr](https://kosai.kr/r/011500.html?utm_source=openai))

- 한계(중요)
  - 부문별 ‘영업이익’·‘영업이익률’은 회사가 공시하지 않는 경우가 많아, 제가 제시한 부문별 이익·이익률은 “회사 공시가 아닌 경우 단순 추정치”임. 투자·의사결정 목적으로 정확한 부문별 이익구조가 필요하면 DART(사업보고서·반기보고서)의 ‘영업부문정보’ 원문(표)을 직접 XBRL/PDF로 추출해 정확히 확인하거나, IR에 ‘부문별 영업이익 공개 여부’를 질의하는 것이 권장됩니다. ([opendart.fss.or.kr](https://opendart.fss.or.kr/xbrl/viewer/main.do?rcpNo=20260814002881))

- 추가로 도와드릴 수 있는 항목(선택)
  1. 원하시면 DART 원문(반기보고서/사업보고서)의 ‘영업부문정보’ 표를 PDF/XBRL에서 직접 스크랩하여 부문별(매출·영업이익이 표에 있으면) 정확한 숫자를 추출해 표(엑셀/CSV)로 드리겠습니다.  
  2. 경쟁사 PER을 ‘정밀 비교군(예: 국내 정밀화학·계면활성제 생산업체 상장사들)’으로 한정하여 동일 기준(예: 최근 결산 EPS 기준, 조회일자: 원하시는 날짜)에 맞춰 재산출해 드리겠습니다.  
  3. 위의 “부문별 영업이익(추정)”을 보다 정교하게(공장별 원가·판관비 배분·가동률 반영) 추정해 달시면, 필요한 추가 데이터(예: 부문별 고정비/가동률 또는 공장별 원가비중 등)를 수집해 추정모델로 제시하겠습니다.

원하시는 다음 단계(예: DART 원문에서 ‘영업부문정보’ 표 추출 → 표로 정리 / 경쟁사 목록을 좁혀 동일 기준 PER 재산출 / 부문별 영업이익 정밀추정 중 어떤 작업을 먼저 진행할지)를 알려주시면 바로 수행해서 표·숫자·출처를 명확히 달아 드리겠습니다.
