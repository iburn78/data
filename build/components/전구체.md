# 전구체(리튬배터리용) 산업 개요
- 정의: 전구체는 Ni/Co/Mn 등 금속 수화물(또는 산화물)을 특정 조성·형태로 제조한 중간물질로, 여기에 리튬원료(탄산리튬/수산화리튬)를 결합해 최종 양극활물질(CAM)을 제조한다. 전구체의 입자구조·형상·조성 제어는 최종 전지 성능에 직접 영향.
